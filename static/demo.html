Triage API Endpoint

Use the /api/triage endpoint to get intelligent hospital sorting recommendations based on patient conditions.

Request

POST /api/triage
Content-Type: application/json

{
  "complaint": "chest_pain",
  "severity": 4,
  "age_band": "senior",
  "vitals": {
    "hr": 95,
    "bp_systolic": 160,
    "bp_diastolic": 95,
    "rr": 22,
    "temp": 98.6,
    "o2_sat": 92
  },
  "mode": "rule_based"
}

Response

{
  "recommended_sort": "time",
  "explanation": "Based on high severity and critical vitals...",
  "weights": {
    "time": 0.6,
    "quality": 0.3,
    "rating": 0.1
  },
  "demo_mode_warning": null
}

Example cURL Request

curl -X POST http://localhost:8000/api/triage \
  -H "Content-Type: application/json" \
  -d '{
    "complaint": "chest_pain",
    "severity": 4,
    "age_band": "senior",
    "vitals": {
      "hr": 95,
      "bp_systolic": 160
    },
    "mode": "rule_based"
  }'
