# HospiTrack Quick Start Guide

**🚀 Get HospiTrack live in 5 minutes!**

---

## Prerequisites
- GitHub account
- Render account (free): https://render.com/signup

---

## Step 1: Push Code to GitHub (2 minutes)

```bash
cd /home/ubuntu/hospitracker

# Option A: Using GitHub CLI
gh auth login
git push origin main

# Option B: Using Personal Access Token
# Create token at: https://github.com/settings/tokens
git push origin main
# Enter username and token when prompted
```

**Verify:** Check https://github.com/JZembower/HospiTrack/commits/main

---

## Step 2: Deploy to Render (3 minutes)

### One-Click Deploy:
1. Visit: https://render.com/deploy?repo=https://github.com/JZembower/HospiTrack
2. Click "Connect GitHub"
3. Choose service name: `hospitracker`
4. Click "Create Web Service"
5. Wait 5-10 minutes for build to complete

### Your URL:
```
https://hospitracker-XXXX.onrender.com
```
(XXXX will be auto-generated by Render)

---

## Step 3: Verify Deployment (1 minute)

Open your Render URL and test:

✅ **Landing Page** - Should display hero section with 3 feature cards  
✅ **Find Care** - Search "San Francisco, CA" for chest pain  
✅ **Explore** - Should show 4,088 hospitals on map  
✅ **Demo** - Submit triage form with ML mode ON  
✅ **API Docs** - Visit `/docs` for interactive API

---

## Done! 🎉

Your HospiTrack is now live and publicly accessible.

## Troubleshooting

**Build fails?**
- Check Render logs in dashboard
- Verify `Dockerfile.prod` is in repository

**Health check fails?**
- Wait 2-3 minutes for initial startup
- Check logs for Python errors

**"No hospitals found"?**
- Increase radius to 100 km
- Try coordinates: lat=37.7749, lon=-122.4194

**Need help?**
- Read full guide: `ACTUAL_DEPLOYMENT_STEPS.md`
- Contact: Render support at https://render.com/support
