### Deployment Platform: Render.com

**Why Render?**
- ✅ Free tier available (512 MB RAM)
- ✅ Automatic HTTPS/SSL certificates
- ✅ Docker support (uses our Dockerfile.prod)
- ✅ Health checks and auto-restart
- ✅ One-click deployment from GitHub

**Resource Usage:**
- Memory: ~200 MB average (512 MB limit on free tier)
- CPU: Minimal (<5% average)
- Storage: 4.9 MB (data + models + static)
- Build time: 8-10 minutes (first deployment)
- Cold start: ~30 seconds (free tier only)

### Environment Variables

These are pre-configured in `render.yaml`:

```
PORT=10000                           # Auto-set by Render
PYTHONUNBUFFERED=1                   # Python output buffering
HOSPITRACK_DATA_PATH=/app/data       # Hospital data location
GEOCODING_CACHE_SIZE=1000            # Location cache size
ML_DEMO_ENABLED=true                 # Enable ML triage demo
LOG_LEVEL=INFO                       # Logging verbosity
```

You don't need to set these manually - Render will use `render.yaml` automatically.

## 🐛 Known Issues & Solutions

### Issue 1: GitHub Authentication
**Problem:** `fatal: could not read Username for 'https://github.com'`

**Solution:** Use one of these methods:
1. **GitHub CLI**: `gh auth login` (easiest)
2. **Personal Access Token**: Create at https://github.com/settings/tokens
3. **SSH**: `git remote set-url origin git@github.com:JZembower/HospiTrack.git`

### Issue 2: Render Build Timeout
**Problem:** Build exceeds 15 minutes on free tier

**Solution:**
- This is unlikely (our build takes ~8 minutes)
- If it happens, retry the deployment
- Consider upgrading to paid tier ($7/month) for faster builds

### Issue 3: Geocoding Timeouts
**Problem:** Some addresses fail to geocode within 30 seconds

**Solution:**
- This is expected for obscure/international addresses
- Recommend users click "Use My Location" button
- Or enter lat/lon coordinates directly
- Cache helps reduce timeouts for popular locations

### Issue 4: Cold Starts (Free Tier)
**Problem:** First request after 15 minutes of inactivity takes ~30 seconds

**Solution:**
- Free tier spins down after inactivity (expected behavior)
- Upgrade to paid tier ($7/month) for always-on service
- Or set up a cron job to ping `/healthz` every 10 minutes:
  ```bash
  */10 * * * * curl https://hospitracker-XXXX.onrender.com/healthz
  ```
